# Bundled loops

All 15 loops here are synthesized with numpy (see `scripts/generate_loops.py`), not sampled or
sourced from any external pack. There is no licensing question because nothing was recorded or
copied — every waveform is generated by code at build time. Regenerate with:

```bash
python scripts/generate_loops.py
```

`manifest.json` lists each loop's native BPM and bar count, used by `djmcp.tools.mix.overlay_loop`
to time-stretch a loop to match a track's tempo before overlaying it.
